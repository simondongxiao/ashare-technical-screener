# A-Share Technical Screener

This repository hosts the static GitHub Pages version of the A-share technical screener.

Open `index.html` through GitHub Pages. The file is generated locally from:

- `D:\codex\work\ashare_technical_screener.py`
- `D:\codex\work\build_ashare_technical_screener_html.py`

Daily update is handled by the local script:

- `D:\codex\work\update_and_publish_ashare_pages.ps1`

The HTML is a static snapshot. It updates for viewers only after the local update script commits and pushes a new `index.html`.
